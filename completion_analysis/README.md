# 有根分裂距离补全求解器（rf_completion_bounds.py）

对两棵含未解析多分叉、且相对目标叶集合缺叶的资料树，在**所有合法补全**上求
有根分裂距离的最小值与最大值，并为每个端点附一对实际可行的补全树（见证）。

## 距离口径（明确定义）

对叶集合为 L 的已补全（二叉）树 T，记 C(T) 为其**非平凡有根 clade（分裂）**
集合，即大小为 2..|L|−1 的簇。两棵补全树 T1、T2 的距离为对称差：

```
d(T1, T2) = |C(T1) \ C(T2)| + |C(T2) \ C(T1)|
          = 2·(|L| − 2) − 2·|C(T1) ∩ C(T2)|
```

平凡分裂（单叶与全叶集）在所有补全中相同，在对称差中抵消，故不计入。

## 合法补全的定义

资料树 T 的合法补全是满足以下条件的、叶集合恰为目标集合的二叉有根树：

1. 每个缺失叶被挂到**显式允许**的补叶位置之一（某条边，或根边 `ROOT`，
   即成为整棵树的姐妹）；
2. 每个多分叉被解析为某种二叉细分（refinement）。

未知分裂**绝不**按零支持计分：距离只在完全解析的补全之间计算，从不直接
对未解析的资料树计分。

## 端点真实性

报告的最小值与最大值**总是**由一对真实补全达到，并随结果返回见证树对
（`min_witness` / `max_witness`，附合法性校验标志）。不会把来自互不
相容补全的局部界拼成假端点。

## 状态语义（严格区分）

- `exact`：全部补全对评估完毕，min/max 为精确值，均有见证。
- `budget_exhausted`：搜索预算耗尽。分别报告：
  - 最小值：`proven_lower_bound ≤ min ≤ best_witnessed`
  - 最大值：`best_witnessed ≤ max ≤ proven_upper_bound`

  已证明界对整个补全空间有效（见下），见证为已找到的最优真实补全对。
- `infeasible`：约束本身无解（资料树含目标集合外的叶、或某缺失叶无任何
  允许位置），与预算不足严格分开报告。
- `invalid_input`：输入非法（如补叶位置的 clade 匹配不到节点）。

## 已证明界的推导

- **min 下界**：对每棵树求*强制分裂*集合 F（在所有合法补全中都存在的
  clade：资料树中其子树内没有允许补叶位置的非平凡 clade——细分只会增加
  分裂、不会删除；挂在该节点上方或入边上的补叶不改变其 clade）。凡属于
  F1 却不可能出现在 T2 任何补全中的分裂（与 T2 的 clade 集不相容），必然
  对每对补全的距离各贡献 1，双侧求和即下界。
- **max 上界**：任何补全对共享全部分裂至少包含 F1 ∩ F2，故
  `d ≤ 2·(n−2) − 2·|F1 ∩ F2|`。
- 可能分裂的判定采用保守超集（只检查与资料树 clade 的嵌套/不相交相容性，
  忽略补叶位置约束），保证界合法（可能偏松）。

精确模式下会内部断言 `下界 ≤ min` 且 `max ≤ 上界` 作为一致性自检。

## 用法

```
python3 rf_completion_bounds.py example.json
```

输入 JSON 格式见 `example.json`：

- `target_leaves`：目标叶集合；
- `tree1`/`tree2`：`newick` 字符串 + `allowed_attachments`，每个位置为
  `"ROOT"` 或一个叶的列表（表示具有该后代叶集合的节点上方的边）；
- `budget`：`max_completions_per_tree` 与 `max_pair_evaluations`。

## 测试

```
python3 -m pytest test_rf_completion_bounds.py -p no:rerunfailures
```

覆盖：精确 min/max 与暴力复核、见证合法性校验（含非法补全的拒绝）、
未知分裂不按零支持计分、infeasible 与 budget_exhausted 的区分、
已证明界与精确解/见证的一致性。
