.. _v3.1.0:

3.1.0
=====

Enhancements
------------

* Added :mod:`pynetdicom.handover` for linking completed transfers to their
  Storage Commitment results, including partial failures and late results
* Added Storage Commitment support to the ``qrscp`` application

Fixes
-----

* Fixed the default logging handlers for N-ACTION treating *Action Type ID* as mandatory (:issue:`1027`)
* Fixed being unable to resolve IPv4 address when using the hostname (:issue:`1033`, :pr:`1034`)
