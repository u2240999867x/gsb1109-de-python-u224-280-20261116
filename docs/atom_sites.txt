# Correlating atomic sites across files

The `CifFile.atom_sites` module associates the atomic sites of two
structure descriptions, typically two CIF data blocks from different
files. It works from the unit cell, fractional coordinates, element
symbols and the symmetry operations allowed by each structure.

## Building a structure

A `Structure` holds the original site labels, normalised element
symbols, fractional coordinates, unit cell parameters, symmetry
operations and disorder/occupancy information. Structures can be read
directly from a PyCIFRW data block or a CIF file, or built from plain
Python sequences:

    from CifFile import ReadCif
    from CifFile.atom_sites import Structure, correlate_structures

    cf = ReadCif("structure.cif")
    structure_a = Structure.from_cif_block(cf[cf.keys()[0]], name="file1")
    structure_b = Structure.from_cif("other.cif", block="data_I")

Numeric values such as `0.7141(3)` are converted using PyCIFRW's ESD
handling. Elements come from `_atom_site_type_symbol`, falling back to
the element prefix of `_atom_site_label`. Symmetry operations are read
from `_space_group_symop_operation_xyz` (CIF 2.0) or
`_symmetry_equiv_pos_as_xyz` (CIF 1.1); the identity is assumed when no
operations are present.

## Correlation rules

Two sites can only correspond when they have the same element and the
same disorder signature (`_atom_site_disorder_assembly` /
`_atom_site_disorder_group`). Sites of different elements, or ordered
sites versus mutually exclusive disorder occupants, are never merged
even when their coordinates coincide.

Every symmetry image of every site is generated modulo lattice
translations before comparison. Fractional-coordinate differences are
compared under periodic boundary conditions, so images related across a
cell face still correspond. An optional Cartesian tolerance (in
Angstrom) can be supplied in addition to the fractional tolerance:

    result = correlate_structures(structure_a, structure_b,
                                  fractional_tol=1e-3,
                                  cartesian_tol=0.02)

## Equivalence evidence and original labels

Each retained relation keeps the original labels from both structures
and an `evidence` list. Every evidence item records the symmetry
operation (index and xyz string) from each structure that produced the
matching images, the symmetry-expanded fractional coordinates, the
lattice shifts applied while wrapping images into the unit cell, and the
integer `boundary_shift` connecting the two images across a periodic
boundary. Special positions that are generated by several operations
contain one evidence entry per operation combination, so no equivalence
path is lost.

## Certain and ambiguous relations

All maximum-cardinality global matchings are enumerated (up to
`matching_cap`). The returned `CorrespondenceResult` separates:

* `certain`: relations present in every global solution;
* `ambiguous_groups`: connected groups of sites whose pairing changes
  between solutions, with every alternative relation and its evidence;
* `unmatched_a` / `unmatched_b`: labels no maximum matching can cover.

The `status` attribute is one of `unique`, `ambiguous`, `partial` or
`ambiguous_partial`, and `to_dict()` returns a plain-data
representation including every enumerated solution. When the matching
cap is reached, `truncated` is set and only relations forced by the
local candidate graph are reported as certain.
